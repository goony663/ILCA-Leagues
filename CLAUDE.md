# ILCA Leagues site

Before changing anything in this repo, read `UPDATING.md`. It covers how to update the calendar and results and how to publish.

Key rules:
- Pushing to `main` publishes to the live federation website.
- Never commit ID numbers, birth dates or xlsx files.
- `elite.html` and the league pages are generated; edit their sources in `tools/`.
- Always pull first, and summarize the change for the person before pushing.
