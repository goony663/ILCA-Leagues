# ILCA Competitions pages

Public competition pages of the Israel Climbing Federation (התאחדות הטיפוס בישראל), season 2026/27.
Design by Noam ("דף תוצאות התאחדות הטיפוס"); built as plain HTML for GitHub Pages and embedded in ilca.org.il with an iframe (`embed.html`).

- `index.html` – landing page, all leagues (תחרויות לאומיות)
- `elite.html` – ליגת העל
- `data/calendar.json` – upcoming competitions of all leagues (from the federation's competitions sheet)
- `data/updates.json` – lines for the updates bar (עדכונים)
- `assets/` – shared styles, script, fonts (Karantina, Heebo – SIL OFL), logo

Routine updates change only the files in `data/`.
